# Weapon data verification and proposed changes

Reviewed on 2026-11-17 on `feat/game-data-refresh`. These changes update Karl’s stored data to the cited official wiki revisions. They have been prepared and tested; this audit did not apply them to the connected database. The comparison starts after the earlier Shard Diffractor pilot was applied locally.

## Coverage

Compared the base-stat tables, upgrade effects and prices, and overclock effects and prices for **24 weapons, 308 upgrades, and 160 overclocks**. All expected weapons and overclocks are present. The LOK-1 Aperture Extension row was checked manually because its icon is commented out in the wiki source.

The proposed import changes **101 fields in 46 records across 18 weapons**: 25 stat entries, 70 credit/mineral fields, and 6 descriptions. A field count includes a newly represented statistic or a removed incorrect modifier.

Existing IDs, names, class assignments, tier/overclock slots, and saved-loadout links are preserved. Records are updated in a transaction; unexpected slot identities or unreviewed upgrade effects stop the import. Wiki spelling variants have not been used to rename existing records.

This is a review against reference tables. Wiki pages can be stale, omit hidden mechanics, or round values. The follow-up section records those limits explicitly. Existing fields that the tables do not document have been retained; inclusion in the dataset does not certify those fields or the advanced DPS calculations.

## Gameplay-stat and description corrections

- PGL Homebrew Explosive: remove the incorrect direct-damage multiplier; keep randomized area damage represented by its x1.1 average.
- Breach Cutter: use 1.5 for the nominal base width and +1.5 for Loosened Node Cohesion and Spinning Death. Descriptions identify these as equipment-terminal units; the game silently scales the projectile.
- Deepcore GK2 AI Stability Engine: spread-recovery multiplier changes from x2.11 to x9.
- M1000: base reload time changes from 2.5s to 2.55s. The calculator’s decimal handling remains a follow-up.
- CRSPR Heat Radiance: the displayed area-heat bonus changes from 10 to 80, matching the existing description.
- Subata: add the omitted 50% base armor-breaking stat; Automatic Fire’s recoil penalty changes from x2.5 to x3.5.
- Minigun: expose cooling delay, maximum-accuracy duration, and overheat duration, plus the existing upgrades’ associated timing bonuses.
- Thunderhead: expose starting rate of fire and its upgrade bonuses. Neurotoxin Payload’s radius bonus becomes a x1.25 multiplier instead of a flat +0.3.
- LOK-1: add the omitted 150% base armor-breaking stat.
- Hurricane Rocket Barrage: explicitly zero the displayed turn rate when guidance is disabled.
- Boltshark: add the normal bolt’s omitted 100% stun chance and 1s duration.

These data entries improve the displayed stat tables. Conditional damage, effective burst/lock rates, heat cycles and advanced metrics are not regenerated by the import.

## Preview and application

Run the read-only inventory/integrity/reference audit:

```sh
php artisan app:audit-game-data
```

Preview every proposed database change:

```sh
php artisan app:sync-game-data
```

Preview a single weapon using its exact database name:

```sh
php artisan app:sync-game-data --weapon='Deepcore GK2'
```

Apply the reviewed dataset when ready:

```sh
php artisan app:sync-game-data --apply
```

An identical second import makes no changes. Removing the old PGL Homebrew direct-damage modifier requires its previous value to match the reviewed value; a locally altered effect is rejected for review.
